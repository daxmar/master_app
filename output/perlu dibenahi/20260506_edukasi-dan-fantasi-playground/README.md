# Edukasi dan Fantasi Playground

Aplikasi edukasi dan fantasi playground yang menyatukan tema Edukasi, dengan nuansa Fantasi dan fungsi Jaringan. Dibangun sebagai prototype sederhana menggunakan Python untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Edukasi
- Fantasi
- Jaringan

## Bahasa Pemrograman
- Python

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat UI web proyek dan instruksi run.
