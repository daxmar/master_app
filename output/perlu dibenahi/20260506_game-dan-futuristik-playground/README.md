# Game dan Futuristik Playground

Aplikasi game dan futuristik playground yang menyatukan tema Game, dengan nuansa Futuristik dan fungsi Sudut pandang. Dibangun sebagai prototype sederhana menggunakan Go untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Game
- Futuristik
- Sudut pandang

## Bahasa Pemrograman
- Go

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat UI web proyek dan instruksi run.
