# IoT dan Alam bawah sadar Playground

Aplikasi iot dan alam bawah sadar playground yang menyatukan tema IoT, dengan nuansa Alam bawah sadar dan fungsi Nostalgia. Dibangun sebagai prototype sederhana menggunakan Rust untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- IoT
- Alam bawah sadar
- Nostalgia

## Bahasa Pemrograman
- Rust

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat UI web proyek dan instruksi run.
