# Keamanan dan Cyberpunk Playground

Aplikasi keamanan dan cyberpunk playground yang menyatukan tema Keamanan, dengan nuansa Cyberpunk dan fungsi Kolektif. Dibangun sebagai prototype sederhana menggunakan JavaScript untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Keamanan
- Cyberpunk
- Kolektif

## Bahasa Pemrograman
- JavaScript

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat UI web proyek dan instruksi run.
