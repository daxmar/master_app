# Kesehatan dan Steampunk Playground

Aplikasi kesehatan dan steampunk playground yang menyatukan tema Kesehatan, dengan nuansa Steampunk dan fungsi AI. Dibangun sebagai prototype sederhana menggunakan TypeScript untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Kesehatan
- Steampunk
- AI

## Bahasa Pemrograman
- TypeScript

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat UI web proyek dan instruksi run.
