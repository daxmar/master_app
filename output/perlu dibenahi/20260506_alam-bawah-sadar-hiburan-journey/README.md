# Alam bawah sadar Hiburan Journey

Aplikasi alam bawah sadar hiburan journey yang menyatukan tema Hiburan, dengan nuansa Alam bawah sadar dan fungsi Ritual. Dibangun sebagai prototype sederhana menggunakan Python untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Hiburan
- Alam bawah sadar
- Ritual

## Bahasa Pemrograman
- Python

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat UI web proyek dan instruksi run.
