# Kebiasaan dan Fragmented Playground

Aplikasi kebiasaan dan fragmented playground yang menyatukan tema Kebiasaan, dengan nuansa Fragmented dan fungsi Ritual. Dibangun sebagai prototype sederhana menggunakan HTML untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Kebiasaan
- Fragmented
- Ritual

## Bahasa Pemrograman
- HTML

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat aplikasi HTML langsung.

## Cara Menjalankan
```
# Buka folder proyek dan jalankan kode sesuai bahasa HTML
```
