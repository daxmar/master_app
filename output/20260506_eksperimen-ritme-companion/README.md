# Eksperimen Ritme Companion

Aplikasi eksperimen ritme companion yang menyatukan tema Eksperimen, dengan nuansa Futuristik dan fungsi Ritme. Dibangun sebagai prototype sederhana menggunakan Rust untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Eksperimen
- Futuristik
- Ritme

## Bahasa Pemrograman
- Rust

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal
- `web/` sebagai UI web lokal untuk preview dan prosedur run

## Web UI
- Buka `web/index.html` di browser untuk melihat info proyek dan run instructions.
- Buka `web/index.html` di browser untuk melihat UI web proyek dan instruksi run.
