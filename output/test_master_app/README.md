# Meditasi Produktivitas Journey

Aplikasi meditasi produktivitas journey yang menyatukan tema Produktivitas, dengan nuansa Meditasi dan fungsi VR. Dibangun sebagai prototype sederhana menggunakan JavaScript untuk mengeksplorasi ide kreatif dan kegunaan sehari-hari.

## Tema
- Produktivitas
- Meditasi
- VR

## Bahasa Pemrograman
- JavaScript

## Struktur Awal
- `project.json` sebagai metadata proyek
- `ai_notes.md` sebagai catatan AI Agent
- `src/` sebagai tempat kode sumber awal

## Cara Menjalankan
```
# Buka folder proyek dan jalankan kode sesuai bahasa JavaScript
```
